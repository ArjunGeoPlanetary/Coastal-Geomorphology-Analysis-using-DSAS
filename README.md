# Coastal-Geomorphology-Analysis-using-DSAS
Research focused on the assessment of geomorphological changes along Indian coastlines. This study utilized multi-temporal satellite imagery to map shoreline migration and predict future erosion/accretion trends.

# Coastal Shoreline Change Analysis & Prediction (DSAS)

## Project Overview
A time-series study (2011–2021) of the southwest coast of India using satellite imagery to quantify the impact of engineering structures (harbours) on shoreline stability.

## Technical Workflow
* **Data Processing:** Analysis of multi-temporal satellite data to extract shorelines.
* **Statistical Analysis:** Used the **Digital Shoreline Analysis System (DSAS v5.1)**.
* **Metrics:** End Point Rate (EPR) and Net Shoreline Movement (NSM).
* **Forecasting:** Predicted shoreline positions for 2030 and 2040 using linear regression models.



## Key Findings
* Identified a shift from accretion to intense erosion (average 100m shift) following harbour construction.
* Predicted an additional 140m of erosion by 2040 in high-risk zones.
